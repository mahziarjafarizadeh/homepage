Timeline Controller v.2.2m

This script is an After Effects timeline utility panel that adds a floating UI with several custom tools to manage layers, keyframes, and markers. It creates a palette window called “Timeline Controller v.2.2m” with buttons, each linked to a different function:

• Layer Sequence Organizer → Automatically arranges selected layers in order, either ascending or descending.

• Advanced Layer Sequencer → Lets you set an anchor layer, custom start time, and control gaps between layers for precise sequencing.

• Keyframe Spacing Tool → Redistributes selected keyframes at equal intervals or fits them across a layer’s duration.

• Add Keyframes Tool → Inserts new keyframes before, after, or between selected ones, with options for hold or linear interpolation.

• Timed Marker Master → Adds numbered markers across the composition timeline at specified time intervals, with customizable colors.

• Duplicate at Markers → Duplicates selected layers at every composition marker.

In short, it’s a workflow booster for animators/editors: it speeds up repetitive timeline tasks like sequencing, spacing, duplicating, and adding markers or keyframes.
